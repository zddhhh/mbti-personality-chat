```
## Prompt 架构（System Prompt 分层）

┌─────────────────────────────────────────────────────┐
│                  System Prompt 组装                   │
│                                                      │
│  第1层：基础人格 (mbti.js)                           │
│  ├── 身份信息（网名、头像描述、性别）                   │
│  ├── MBTI 行为特征（4维度各自的行为模式）               │
│  ├── 态度温度（IT冷淡/I温和/T直接/EF正常）             │
│  ├── 性别语言习惯（男生糙/女生语气词）                  │
│  ├── 消息格式规则 + 严格禁止项                         │
│  └── 能力清单（AVATAR/SPLIT/MOMENT/IMAGE）             │
│                                                      │
│  第2层：用户资料上下文 (chat.js)                       │
│  ├── 对方昵称、性别、MBTI、个性签名                     │
│  └── AI 换头像次数状态                                 │
│                                                      │
│  第3层：长期记忆 (agent.js)                           │
│  └── 从历史对话中LLM提取的关键事实                      │
│      (fact/preference/event，最近20条)                  │
│                                                      │
│  第4层：关系状态 (agent.js)                           │
│  ├── 关系阶段（陌生人→认识→朋友→密友）                  │
│  ├── 亲密度、好感度数值                                │
│  └── 当前情绪状态                                     │
│                                                      │
│  组装：fullPrompt = 第1层 + 第2层 + 第3层 + 第4层      │
└─────────────────────────────────────────────────────┘


## 数据流 — 一次完整的对话

用户输入 "我今天吃了火锅 超好吃"
  │
  ├─→ appendMsg('self', ...) 显示到聊天界面
  ├─→ addMessage(sessionId, 'user', ...) 存入IndexedDB
  │
  ├─→ [Debounce 1.5秒] 等用户停下来
  │
  ├─→ agentPreProcess() 
  │     ├─→ 更新 messageCount, lastActiveAt
  │     ├─→ 分析情绪影响
  │     └─→ 每8轮触发 extractMemories() → LLM提取关键信息
  │
  ├─→ 组装 System Prompt (4层叠加)
  ├─→ 取最近40条历史消息
  │
  ├─→ sendChat(apiMessages, 'qwen-plus')
  │     └─→ /api/chat → DashScope qwen-plus
  │
  ├─→ 回复解析：
  │     ├─→ ||AVATAR:海边自拍|| → changeAiAvatar("海边自拍")
  │     │     └─→ /api/avatar → DashScope wan2.6-t2i → Base64
  │     ├─→ ||MOMENT:今天火锅太好吃了|| → addAiMoment(text, sessionId)
  │     ├─→ ||IMAGE:hotpot food|| → LoremFlickr搜图 → 发送图片消息
  │     └─→ ||SPLIT|| → 拆分多条消息，逐条延迟发送
  │
  ├─→ appendMsg('other', ...) 显示AI回复
  ├─→ addMessage(sessionId, 'assistant', ...) 存入IndexedDB
  │
  └─→ agentPostProcess()
        ├─→ 更新关系状态（亲密度/好感度/阶段）
        └─→ scheduleProactiveCheck() 设置主动消息定时器
```
